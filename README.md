# ILAM MART — One-page brand website

Premium responsive concept for **ILAM MART**, positioned as an origin-focused Nepali tea brand from Ilam.

## Files
- `index.html` — semantic one-page markup + SEO / Open Graph metadata
- `styles.css` — responsive editorial design
- `script.js` — scroll header, mobile menu, reveal motion, subtle parallax
- `assets/images/` — optimized prototype imagery

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.

## Content safeguards
This concept intentionally does not invent prices, certifications, awards, farmer counts, production statistics, exact grades, export destinations, phone/email details, or a precise street address.

The brewing component is intentionally left as a UI placeholder until product-specific packaging instructions are supplied.

The Farmers Tea relationship is written neutrally rather than asserting an unconfirmed legal/corporate structure.

## Photography
The prototype uses web-optimized Creative Commons images from Wikimedia Commons. Attribution is included in the footer. For a production brand site, replace these with client-owned ILAM MART / Farmers Tea photography where possible.
